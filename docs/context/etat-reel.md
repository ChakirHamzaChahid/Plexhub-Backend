### Nouveaux findings de l'audit v1 (lignée `AUDIT-*`) — les plus structurants
Détail complet + Top-10 priorisé + roadmap V1/V2/V3 : `docs/audit/v1/FINAL-REPORT.md`. **Aucun S1.**
